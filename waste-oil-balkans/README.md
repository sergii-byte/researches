# Проект: завод регенерации отработанных масел в базовое масло API Group II (Бургас, Болгария)

Пакет документов для китайского партнёра и для принятия инвестиционного решения.
Цели по сырью: **этап 1 — 10 000 т/год, этап 2 — 20 000 т/год, этап 3 (проектная) — 30 000 т/год**,
с дальнейшим масштабированием по мере наращивания сырьевой базы.

## Документы (`dist/`)

1. **01_Poyasnitelnaya_zapiska.docx** — Пояснительная записка (RU + 中文).
   Суть проекта, рынок сырья и сбыта, законодательство, технология JingJin, экономика, риски.
2. **02_Plan_realizacii.docx** — План реализации.
   Сроки по болгарскому и европейскому законодательству, разрешительная фаза (ОВОС + КР/IPPC),
   оборудование JingJin, СМР, пусконаладка, сырьевая программа, CAPEX, stage-gates.
3. **03_Chestny_analiz_rynka.docx** — Честный анализ рынка.
   Ситуация с отработанными маслами в Болгарии и у соседей; действующие заводы; цены с доказательствами;
   законы; **государственные предприятия как источник сырья**; сырьёвой баланс и справка по «большому сегменту».
4. **04_Proverka_faktov.docx** — Независимый фактчек всех цифр и утверждений (статусы:
   Подтверждено / ИСПРАВЛЕНО / Частично / Нет данных). Исправлено 4 неточности + 1 техническое уточнение.
5. **05_Ekonomika_TAM_SAM_SOM_istochniki.docx** — Экономика этапа 1 (10 000 т/год): выручка, OPEX,
   EBITDA, CAPEX/оборудование, окупаемость; **TAM/SAM/SOM** (продукт и сырьё); **карта всех источников
   сырья** (генераторы, госпредприятия, агрегаторы, порты, трансграничные каналы). Все суммы — оценки, не котировки.

## Ключевые честные выводы

- Цели **10–20–30 тыс. т/год** реалистичны по сырью: этап 1 меньше сегодняшнего легального сбора Болгарии;
  30 тыс. т/год покрываются сбором + регионом + тендерами госпредприятий + умеренным импортом.
- Ниша Group II в ЕС-части Балкан свободна (никто не производит); рынок сбыта в радиусе 800 км дефицитен.
- Госпредприятия (Мини Марица-изток, ТЕЦ/АЭС, БДЖ, Столичен електротранспорт и др.) обязаны сдавать
  отработанное масло лицензированным операторам через **публичные тендеры на продажу** — прозрачный канал.
- «Большой сегмент» (десятки тыс. т в **месяц**) достижим только как импортный хаб — стратегический горизонт,
  а не текущая цель. Приведён как справка.

Все ключевые цифры снабжены проверяемыми источниками (раздел «Источники» в каждом документе).
Дата среза: сентябрь 2026 г.

## Пересборка документов

```bash
cd waste-oil-balkans
npm install docx
node src/build_zapiska.js dist/01_Poyasnitelnaya_zapiska.docx
node src/build_plan.js    dist/02_Plan_realizacii.docx
node src/build_analiz.js  dist/03_Chestny_analiz_rynka.docx
```
